# Ludo Studio

कंप्यूटर पर `index.html` को किसी भी आधुनिक browser में खोलें।

## Android पर install करना

1. इस `ludo-studio` folder को किसी web host (जैसे GitHub Pages, Netlify या अपनी website) पर डालें।
2. Android Chrome में उसका HTTPS link खोलें।
3. Chrome menu (तीन dots) → **Install app** या **Add to Home screen** चुनें।

फिर गेम phone पर app की तरह खुलेगा। APK बनाने के लिए Android build tools और signing key की आवश्यकता होती है; यह project PWA format में तैयार है।

## Customization

- गेम का नाम बदलें
- 2 से 4 खिलाड़ी चुनें
- खिलाड़ी का नाम और रंग बदलें
- बोर्ड theme चुनें
- जीत के लिए गोटियों की संख्या बदलें

सेटिंग बदलने के बाद **सेटिंग्स लागू करें** दबाएँ।

## वर्तमान gameplay

- पासा फेंकना और turn rotation
- 1 या 6 पर घर से गोटी निकालना
- गोटी को click करके चलाना
- प्रतिद्वंद्वी की गोटी काटना
- 6 आने पर अतिरिक्त turn
- कंप्यूटर opponents और उसी फोन पर दोस्त के साथ pass-and-play

यह starter browser app है—इसे बाद में online multiplayer, sound effects, timers, login या Android packaging के साथ आगे बढ़ाया जा सकता है.
